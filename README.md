This is the old version of my AI-Swedish tutor using the Llama 3.1 MLLM downloaded from Ollama and running on Python and Flask.

Using the uv project manager, this program launches a user interface that will question the user in Swedish, answer that question, and provide feedback in English on the user's
spelling and grammatical mistakes.

uv run main.py launches the application
uv run superlim-llm-test.py runs the swewic and sweanalogy tests from SUPER-LIM to grade the Swedish comprehension of the Llama 3.1 MLLM.

I made a newer version of this app in Angular launched on the AWS Amplify app.  Access that repo here: https://github.com/TrollRider-Kristian/AI-Swedish-Whisperer-NG
